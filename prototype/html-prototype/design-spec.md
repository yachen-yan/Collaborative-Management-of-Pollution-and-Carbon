# 污碳协同AI监管平台 — 原型设计规范

## 1. 色彩系统

### 主色
| 名称 | 色值 | 用途 |
|------|------|------|
| 品牌蓝 | `#1677ff` | 主按钮、链接、重点指标 |
| 生态绿 | `#52c41a` | 正常/达标、双减标兵 |
| 预警黄 | `#faad14` | 协同失衡、一般预警 |
| 危险红 | `#f5222d` | paradox、高风险、极差 |
| 辅助橙 | `#fa8c16` | 差、关注区 |

### 中性色
| 名称 | 色值 | 用途 |
|------|------|------|
| 背景灰 | `#f0f2f5` | 页面背景 |
| 卡片白 | `#ffffff` | 卡片、弹窗背景 |
| 边框灰 | `#d9d9d9` | 分割线、边框 |
| 主文字 | `rgba(0,0,0,0.88)` | 标题、正文 |
| 次文字 | `rgba(0,0,0,0.45)` | 辅助说明、时间 |
| 禁用灰 | `rgba(0,0,0,0.25)` | 禁用状态 |

### C-P 协同指数色阶
| 等级 | 指数 | 色值 |
|------|------|------|
| 优 | ≥0.8 | `#52c41a` |
| 良 | 0.6-0.8 | `#faad14` |
| 差 | 0.4-0.6 | `#fa8c16` |
| 极差 | <0.4 | `#f5222d` |

## 2. 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 24px | 600 | 页面级标题 |
| 模块标题 | 18px | 600 | 卡片标题、区块标题 |
| 正文 | 14px | 400 | 常规文本、表单标签 |
| 辅助文字 | 12px | 400 | 时间、说明、脚注 |
| 数据大数字 | 36px | 700 | 核心指标、评分 |
| 数据指标 | 20px | 600 | 次要指标 |

字体栈：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`

## 3. 间距规范

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 紧凑内边距 |
| md | 16px | 卡片内边距、列表项间距 |
| lg | 24px | 模块间距 |
| xl | 32px | 页面级外边距 |

卡片圆角：`8px`
卡片阴影：`0 2px 8px rgba(0,0,0,0.08)`

## 5. 全局组件

### 顶部导航栏
- 高度：`64px`
- 背景：`#1677ff`
- 左侧：Logo + 平台名称
- 右侧：用户头像 + 企业名称 + 退出

### 侧边菜单（企业端）
- 宽度：`200px`
- 背景：`#ffffff`
- 选中态：左侧 `3px` 品牌蓝竖线 + 背景 `#e6f4ff`
- 菜单项：工作台、月度填报、实时看板、悖论模拟器、三评报告、预警中心

### 内容区
- 背景：`#f0f2f5`
- 内边距：`24px`
- 卡片布局，栅格 `24` 列
