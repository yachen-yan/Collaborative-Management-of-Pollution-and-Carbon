# 污碳协同 AI 监测预警分析平台 — 产品需求文档（PRD）

> **版本**：v3.1 — 工业涂装 MVP 专版（增量修订）  
> **日期**：2026-05-20  
> **主题**：AI + 生态监测预警分析  
> **范围**：最小可行产品（MVP），聚焦工业涂装行业的多污染物与碳排放协同监测预警。v3.1 增量扩展：多排口监测、多污染物协同指数（MCI）、环境健康综合评价（EHI）、全生命周期碳管理（LCA）、政府端企业/数据/设备管理功能

> **核心定位**：不区分"企业端/审批端"，不承载审批职能。平台是一个**纯监测预警分析工具**，围绕 "AI + 生态" 构建从数据采集 → 智能计算 → 异常预警 → 因果归因 → 决策支持的完整闭环。通过 AI 将企业的污染排放、能源消耗、碳排放三股数据实时联动计算，自动识别"减污增碳"和"减碳增污"的 减污增碳/减碳增污悖论 现象，为工业企业自查自纠和政府精准监管提供数据支撑。
>
> **AI + 生态监测预警数据流：**
> ```
> 数据采集层（CEMS/RTO/电表/台账）
>     → AI 实时双算引擎（污算子/碳算子/协同算子）
>     → AI 悖论识别引擎（C-P 协同指数 + 规则判定）
>     → 智能预警生成（分级推送：企业/监测科/管理科）
>     → AI 因果归因（LLM 时序分析 + 关联图谱）
>     → 决策支持输出（三评合一报告 / 调度建议 / 政策秒查）
> ```

## 🎯 系统核心北极星指标

**悖论识别率**：系统能否准确、实时地从海量数据中，揪出"为了降 VOCs 而狂烧天然气（减污增碳）"或"为了保碳配额而关停治污设备（减碳增污）"的企业。

| 指标维度 | 计算方式 | 目标值 |
|----------|----------|--------|
| 悖论识别率 | 系统识别出的 减污增碳/减碳增污悖论 案例数 / 实际存在的 减污增碳/减碳增污悖论 案例总数 | ≥ 85% |
| 误报率 | 系统误报的 减污增碳/减碳增污悖论 案例数 / 系统总报警数 | ≤ 15% |
| 双算响应时效 | 从数据上报到计算结果呈现的平均时间 | ≤ 5 分钟 |
| 三评报告生成率 | 生成三评合一报告的企业数 / 建档企业总数 | ≥ 90% |

## 1. 用户角色与核心场景

平台面向三类用户，各自的核心诉求和使用场景如下：

### 用户 1：工业企业（环保经办人 / 生产主管）

**核心诉求：**
- 知道自己每天/每月的 VOCs 排了多少、碳排了多少
- 知道换水性漆到底划不划算（会不会反而增碳）
- 收到异常预警时，知道问题出在哪、怎么改
- 向政府提交数据时，一次填报、多处复用

**核心场景：**

**场景 A-1：月度数据自报**
> 每月初，企业环保经办人登录平台，填报上月涂料消耗量（溶剂型/水性/粉末分列）、RTO 运行时长、天然气消耗量、**企业总用电量/绿电量/化石能源用电量**。系统自动调用 OCR 解析上月台账 PDF，一键回填关键字段。填报完成后，5 分钟内看到实时双算结果：VOCs 排放强度、碳排强度、C-P 协同指数。

**场景 A-2： 减污增碳/减碳增污悖论 预警响应**
> 某天下午，系统检测到企业 RTO 天然气消耗环比激增 45%，但 VOCs 排放反而下降，C-P 协同指数跌破 0.5。企业经办人收到站内消息 + 短信预警，打开平台查看 减污增碳/减碳增污悖论 诊断报告："检测到 RTO 空烧时长占比升至 22%，原因：喷涂排班过于分散。建议：集中排班或引入沸石转轮浓缩。"企业调整后，C-P 指数回升，系统自动销号。

**场景 A-3：涂装技改前预评估**
> 企业计划将溶剂型涂料切换为水性涂料，在平台「悖论模拟器」中输入当前工艺和拟改造工艺。系统双算后输出："VOCs 预计降低 60%，但天然气消耗预计增加 35%，C-P 协同指数将从 0.75 降至 0.48，属于【减污增碳陷阱】。建议：同步引入热泵辅助烘干。"

**场景 A-4：查看三评合一报告**
> 每月 5 日，系统自动生成本月「污-能-碳三评合一报告」。企业经办人查看报告：污染评价 82 分（良）、能效评价 65 分（一般）、碳排评价 58 分（较差）、C-P 协同指数 0.52（差）。AI 摘要指出最优先改进项：减少 RTO 空烧。报告可导出 PDF 存档。

- 快速定位问题企业和问题环节，精准下发管理建议
- 不用翻法规书，问 AI 就能查到最新标准
- 生成汇报材料时，系统自动出图表和文字

**核心场景：**

**场景 B-1：一屏观全域**
> 管理科工作人员打开平台首页，看到「协同管控指挥大屏」：当前区域协同指数 62（关注区），今日 减污增碳/减碳增污悖论 预警 3 条，处置中任务 2 条，已闭环 15 条。大屏下方滚动显示最新 减污增碳/减碳增污悖论 事件：张三汽修厂 C-P 指数 0.42（减污增碳）、李四喷涂厂 C-P 指数 0.38（减污增碳）。

**场景 B-2：AI 异常归因与调度**
> 工作人员在 LLM 助手输入框提问："为什么张镇工业园这两天协同指数掉了？" LLM 助手 3 秒后回复："经溯源，园区 3 家企业同时拉满 RTO 负荷求 VOCs 达标，天然气总耗环比增 28%。"助手同时生成调度建议："建议错峰运行：张三厂 8–12 时、李四厂 13–17 时、王五厂 18–22 时。"工作人员一键下发调度指令至企业。

**场景 B-3：政策秒查**
> 工作人员问 LLM："RTO 燃烧室温度最低多少度？" LLM 秒回："《工业涂装行业挥发性有机物治理技术指南》第 4.2.3 条：760°C 以上，确保分解效率 ≥ 99%。北京市 DB11/501-2023 补充：低于 760°C 持续 15 分钟以上视为不正常运行。"

**场景 B-4：自然语言报表生成**
> 工作人员输入："生成上个月园区 减污增碳/减碳增污悖论 风险统计。"系统自动生成包含图表的统计报告：7 起 减污增碳/减碳增污悖论 事件（5 起减污增碳、2 起减碳增污）、重点企业名单、协同指数变化趋势。支持导出 Word/PDF。

### 用户 3：政府监测数据科（生态环境局监测科室）

**核心诉求：**
- 实时掌握辖区内每家企业 VOCs 和碳排的动态变化
- 在 3D 地图上看到哪家企业在闪红灯（减污增碳/减碳增污悖论）
- 企业上报的数据质量是否可靠，有没有造假嫌疑
- 自动生成监测周报/月报，不用手动拼 Excel

**核心场景：**

**场景 C-1：3D GIS 实时监测**
> 监测科人员打开「3D GIS 污碳协同监测台」，看到辖区内涂装企业以气泡形式悬浮在 3D 地图上。红色闪烁气泡 = 减污增碳/减碳增污悖论 高风险企业（C-P < 0.4），绿色气泡 = 双减标兵，灰色气泡 = 数据不足。点击红色气泡，镜头飞至该企业上空，右侧弹出实时数据：VOCs 28 mg/m³、RTO 温度 785°C、天然气 1.2k Nm³/h、C-P 指数 0.42。

**场景 C-2：数据质量审核**
> 企业提交月度数据后，系统自动进行 AI 校验：涂料用量与喷涂面积比值偏离行业均值 60%，标记「数据异常请核实」。监测科人员查看校验结果，确认该企业填报有误，退回要求重新填报。若数据通过校验，自动进入实时双算引擎。

**场景 C-3：跨区转移溯源**
> 系统检测到某主机厂 VOCs 骤降 80%，同时关联外包厂 VOCs 新增 70%，在 3D 地图上自动生成红色飞线。监测科人员点击飞线，查看转移详情："A 厂将喷涂外包给 B 厂，疑似污染转移。"标记为「重点关注」。

**场景 C-4：自动生成监测月报**
> 每月初，系统自动汇总上月所有企业的 VOCs 排放、碳排放、C-P 协同指数、减污增碳/减碳增污悖论 事件，生成《XX 区工业涂装行业污碳协同监测月报》。监测科人员审核后一键发布至管理科。

## 3. 数据底座 —— 双源数据注入与实时双算

### 3.1 数据注入通路

**数据流架构（两条独立管线）：**

```
管线 1：实时数据流（用于 减污增碳/减碳增污悖论 实时预警）
API 直采（5–15 分钟级）
    → 实时双算引擎（污算子/碳算子/协同算子）
    → AI 悖论识别引擎
    → 智能预警生成（企业/监测科/管理科分级推送）

管线 2：月度数据流（用于三评合一报告和区域统计）
月度填报 + OCR 解析
    → AI 数据质量审核（6 条校验规则）
    → 监测数据科审核
    → 月度分析池
    → AI 三评合一报告生成
    → 区域协同指数计算
```

**通路 A：API 结构化直采（规上企业）— 管线 1**

> **多排口采集原则**：一个企业可存在多个废气排口（如喷涂线排口、烘干线排口、调漆间排口），每个排口独立配置 CEMS 在线监测设备和末端治理设施（RTO/RCO/活性炭吸附等）。平台按 **排口（Outlet）** 维度采集数据，企业级指标由排口数据加权汇总。

**A-1 污染物在线监测（按排口）**

| 数据类型 | 采集频率 | 来源 | 排口适用性 |
|----------|----------|------|-----------|
| TVOC（总挥发性有机物） | 5 分钟 | CEMS 气相色谱/FID | 所有有组织排口 |
| NMHC（非甲烷总烃） | 5 分钟 | CEMS FID | 所有有组织排口 |
| PM2.5 | 15 分钟 | 激光散射法在线监测仪 | 喷涂、打磨排口 |
| SO₂ | 15 分钟 | CEMS 紫外荧光法 | 燃煤/燃气烘干排口 |
| NOₓ（NO + NO₂） | 15 分钟 | CEMS 化学发光法 | 所有高温燃烧排口 |

**A-2 温室气体在线监测（按排口）**

| 数据类型 | 采集频率 | 来源 | 说明 |
|----------|----------|------|------|
| CO₂ | 15 分钟 | 红外吸收法在线监测仪 | 排口直测或燃料消耗反算 |
| CO | 15 分钟 | CEMS 非分散红外法 | 不完全燃烧指示指标 |
| CH₄ | 15 分钟 | 气相色谱/FID | 涂料存储/厌氧过程泄漏监测 |

**A-3 治理设施工况监测（按设施）**

| 数据类型 | 采集频率 | 来源 |
|----------|----------|------|
| 入口污染物浓度 | 5 分钟 | 治理设施入口 CEMS |
| 出口污染物浓度 | 5 分钟 | 治理设施出口 CEMS |
| 去除效率（实时计算） | 5 分钟 | (入口 - 出口) / 入口 × 100% |
| 治理设施运行状态 | 实时 | PLC/DCS 信号 |
| 治理设施能耗（电/天然气） | 15 分钟 | 智能电表/气表 |
| RTO 蓄热体温度（多点位） | 5 分钟 | 热电偶阵列 |
| RTO 热回收效率 | 15 分钟 | (T_出口 - T_入口) / (T_燃烧室 - T_入口) |

**A-4 燃料与能源监测（企业级）**

| 数据类型 | 采集频率 | 来源 |
|----------|----------|------|
| 天然气总消耗量 | 15 分钟 | 厂区总气表 |
| **企业总用电量** | 15 分钟 | 厂区总电表 |
| **绿电量** | 月度 | 企业申报 + 电网核验 |
| **化石能源用电量** | 计算得出 | 总用电量 - 绿电量 |
| 涂料/原辅料入库量 | 日报 | ERP/MES 系统对接 |

**通路 B：智能填报与台账解析（中小企业）— 管线 2**

企业每月登录平台 Web 端，**以企业为核心** 填报以下数据。**一个企业下可能存在多个排口**，排口相关数据作为补充信息录入，用于核算各排口排污情况及治理设施运行工况。

**B-1 企业级核心数据（必填）**
- 涂料使用量（溶剂型 / 水性 / 粉末 / 高固体分 / 稀释剂 / 固化剂分列）
- 涂料供应商及产地（用于计算上游运输碳排）
- 原辅料运输吨公里数（吨数 × 运输距离）
- 天然气总消耗量
- **企业总用电量、绿电量、化石能源用电量**（总用电量 = 绿电量 + 化石能源用电量）
- 喷涂产品面积、成品运输吨公里数
- 产品存储方式及仓储能耗（制冷/温控）

**B-2 排口补充信息（选填，有 API 直采的企业自动回填）**
- 排口编号、排口位置、排口高度、排气筒内径
- 末端治理设施类型（RTO / RCO / 活性炭吸附 / 沸石转轮 + 催化燃烧 / 其他）
- 治理设施设计处理能力（m³/h）、设计去除效率（%）
- 各排口运行时长、废气排放量
- 各排口入口/出口污染物浓度（TVOC、NMHC、PM2.5、SO₂、NOₓ）
- 各排口治理设施能耗

支持上传《排污许可执行报告》《危险废物台账》《原辅料采购单》《运输记录》PDF/Excel，系统自动 OCR 提取关键字段回填表单。

### 3.1a 多排口监测模型

> **核心设计**：**一个企业下可能存在多个排口**。例如，一条完整的涂装产线通常包含喷涂线废气排口、烘干线废气排口、调漆间排口等，每个排口可独立配置末端治理设施。平台既支持按 **企业维度** 汇总核算排污与碳排放，也支持按 **排口维度** 下钻分析各排口的治理效率与排放详情。

**排口 - 治理设施 - 监测点 三级架构：**

```
企业（Enterprise）─ 蓝天工业涂装有限公司
  ├── 基本信息：统一社会信用代码、行业、地址、碳配额
  ├── 能源数据：天然气总消耗、总用电量、绿电量、化石能源用电量  ← 企业级
  │
  └── 排口 1（Outlet）─ 喷涂线废气排口
  │     ├── 治理设施：RTO-01（沸石转轮 + 蓄热燃烧）
  │     ├── 监测点-入口：CEMS-IN-01（TVOC/NMHC/PM2.5/SO₂/NOₓ/CO/CH₄）
  │     └── 监测点-出口：CEMS-OUT-01（同上）
  │
  └── 排口 2（Outlet）─ 烘干线废气排口
  │     ├── 治理设施：RCO-01（蓄热催化燃烧）
  │     ├── 监测点-入口：CEMS-IN-02
  │     └── 监测点-出口：CEMS-OUT-02
  │
  └── 排口 3（Outlet）─ 调漆间无组织排放（估算）
        └── 监测方式：手工监测/估算模型
```

**排口级核心计算指标：**

| 指标 | 公式 | 说明 |
|------|------|------|
| 排口污染物排放速率 | 出口浓度 × 废气风量 × 10⁻⁶ | kg/h，按污染物种类分别计算 |
| 排口去除效率 | (入口浓度 - 出口浓度) / 入口浓度 × 100% | 按污染物种类分别计算 |
| 企业级排放速率 | Σ(各排口排放速率 × 排口运行权重) | 运行权重 = 该排口当日运行时长 / 全厂总运行时长 |
| 企业级去除效率 | Σ(各排口去除效率 × 处理风量权重) | 处理风量权重 = 该排口处理风量 / 全厂总处理风量 |

> **设计原则**：当某排口治理设施离线或异常时，该排口数据标记为「离线」，不计入企业级汇总，避免拉低整体指标造成误判。

### 3.2 实时双算引擎 ⭐

**定位**：平台核心计算层。所有接入数据进入引擎后，毫秒级完成"污染-碳排"联动计算，输出 C-P 协同指数和 减污增碳/减碳增污悖论 标记。

**三算子架构：**

```
原始数据流 → 实时双算引擎 → 计算结果流 → 上层应用
    ↑              ↑              ↑
  CEMS/RTO    污算子引擎      VOCs 排放速率/去除效率
  电表/气表   碳算子引擎      CO₂ 排放量/碳排强度
  涂料台账    协同算子引擎     C-P 协同指数/悖论标记
```

**污算子引擎：**
```
VOCs 排放速率（kg/h）= 出口浓度（mg/m³） × 风量（m³/h） × 10⁻⁶
VOCs 去除效率（%）= (入口浓度 - 出口浓度) / 入口浓度 × 100%
VOCs 排放强度（kg/万 m²）= 排放速率 × 运行时长 / 喷涂面积
```

**碳算子引擎：**

```
天然气碳排放（tCO₂/h）= 天然气流量（Nm³/h） × 1.63 × 10⁻⁴
电力碳排放（tCO₂/h）= 化石能源用电量（kW） × 电网因子 × 10⁻³    ← 仅化石能源用电产生碳排
绿电碳排放（tCO₂/h）= 0                                          ← 绿电碳排为 0
涂料隐含碳排放（tCO₂/h）= Σ(涂料用量 × 涂料碳排放因子) / 当月工时
CO 排放（tCO/h）= 天然气流量 × CO 排放因子 × 10⁻⁴          ← 新增
CH₄ 排放（tCO₂e/h）= CH₄ 浓度 × 风量 × GWP_CH₄ × 10⁻⁶    ← 新增，GWP_CH₄ = 28

总碳排放（tCO₂e/h）= CO₂直排 + CO折算 + CH₄折算 + 电力间接(化石能源) + 涂料隐含
总碳排放强度（tCO₂e/万 m²）= 总碳排放 × 运行时长 / 喷涂面积
```

> **注**：CO 按分子量折算为 CO₂ 当量（1 tCO → 1.57 tCO₂e）；CH₄ 按 IPCC AR6 全球变暖潜势 GWP = 28（100年尺度）折算。**绿电不产生碳排放，仅化石能源用电量计入电力碳排放核算**。

**多污染物算子引擎（新增）：**

```
排口 TVOC 排放速率 = 出口 TVOC 浓度 × 风量 × 10⁻⁶                (kg/h)
排口 NMHC 排放速率 = 出口 NMHC 浓度 × 风量 × 10⁻⁶               (kg/h)
排口 PM2.5 排放速率 = 出口 PM2.5 浓度 × 风量 × 10⁻⁶              (kg/h)
排口 SO₂ 排放速率 = 出口 SO₂ 浓度 × 风量 × 10⁻⁶                (kg/h)
排口 NOₓ 排放速率 = 出口 NOₓ 浓度 × 风量 × 10⁻⁶                (kg/h)

企业级某污染物排放速率 = Σ(各排口该污染物排放速率 × 排口运行权重)
```

**协同算子引擎（核心）：**
```
企业级 C-P 协同指数 = max(0, 1 - ΔC / ΔP_threshold)

ΔC = 单位 VOCs 削减带来的碳增量（tCO₂/kg VOCs）
   = (本期碳排放强度 - 上期碳排放强度) / (本期 VOCs 去除强度 - 上期 VOCs 去除强度)

ΔP_threshold = 协同阈值（默认 0.5 tCO₂/kg VOCs，分行业可配置）

区域协同指数 = Σ(企业 C-P 指数 × 企业产值权重) / Σ(企业产值权重)
    （仅统计近 30 天有数据的企业，缺失企业不计入）
```

**C-P 协同指数分级：**

| 指数 | 等级 | 颜色 | 说明 |
|------|------|------|------|
| ≥ 0.8 | 优 | 🟢 | 减污几乎不增碳 |
| 0.6–0.8 | 良 | 🟡 | 减污伴随适度增碳 |
| 0.4–0.6 | 差 | 🟠 | 减污代价过高，触发预警 |
| < 0.4 | 极差 | 🔴 | 典型 减污增碳/减碳增污悖论，强制关注 |

**企业级 C-P 协同指数预警触发条件：**
- C-P < 0.6 持续 4h → 黄色预警（推送企业，提示自查）
- C-P < 0.4 持续 1h → 橙色预警（推送监测数据科，标记重点关注）
- C-P < 0.4 持续 24h → 红色预警（推送管理科，生成管理建议）

**区域协同指数预警触发条件：**
- 区域协同指数 < 70 → 关注区（管理科关注）
- 区域协同指数 < 50 → 危险区（自动推送预警至管理科，触发归因分析）

**典型 减污增碳/减碳增污悖论 场景识别：**

| 场景 | C-P 指数 | 根因 |
|------|----------|------|
| RTO 空烧 | 0.2–0.4 | 入口 VOCs 浓度低，天然气大量浪费 |
| RTO 低效运行 | 0.4–0.6 | 蓄热体老化，热回收效率下降 |
| 过度燃烧 | 0.3–0.5 | 燃烧室温度设定过高 |
| 涂料切换未调参 | 0.4–0.7 | 水性漆 VOCs 降低但烘干能耗激增 |

### 3.3 全生命周期碳管理（LCA）

**定位**：从单一工序端排放视角扩展至 **"摇篮到大门"（Cradle-to-Gate）** 全生命周期视角，帮助企业识别工序端以外的隐性碳排放，避免"工序端减排、上游增碳"的新型悖论。

**工业涂装行业生命周期碳流：**

```
原辅料开采/生产 ──→ 涂料制造 ──→ 运输到厂 ──→ 仓储 ──→ [喷涂工序] ──→ 烘干工序 ──→ 成品仓储 ──→ 运输到下游
   │                  │            │           │         │           │          │           │
  Scope3上游        Scope3上游   Scope3上游   微量     涂料VOCs   天然气/电   微量      Scope3下游
                                                       ↑           ↑
                                                    当前实时双算重点
```

**汽车涂装行业生命周期排放占比参考：**

| 阶段 | 排放占比 | 主要来源 | 数据采集方式 |
|------|----------|----------|-------------|
| 涂料制造（上游） | 25–35% | 涂料生产能耗、原料开采 | 涂料用量 × 涂料碳排放因子 |
| 原辅料运输（上游） | 3–8% | 涂料/稀释剂运输 | 吨公里数 × 运输排放因子 |
| 喷涂工序（过程） | 15–25% | VOCs 排放（无组织）、设备电耗 | CEMS / 电表 |
| 烘干工序（过程） | 30–40% | 天然气/电力消耗 | 气表 / 电表 |
| 末端治理（过程） | 5–10% | RTO/RCO 天然气消耗、电耗 | 气表 / 电表 |
| 成品仓储（下游） | 1–3% | 温控/制冷能耗 | 企业估算 |
| 成品运输（下游） | 2–5% | 物流运输 | 吨公里数 × 运输排放因子 |

**分阶段落地策略（洋葱模型）：**

```
┌────────────────────────────────────────┐
│  核心圈（MVP 已实现）                    │
│  ├─ 喷涂工序 VOCs + 烘干能耗碳排        │
│  ├─ RTO 末端治理能耗碳排                │
│  └─ 电力间接碳排                        │
├────────────────────────────────────────┤
│  中间圈（Phase 2 可扩展）                │
│  ├─ 涂料隐含碳（Scope 3 上游）          │  ← 台账已有涂料用量，只需乘因子
│  ├─ 稀释剂/固化剂隐含碳                 │
│  └─ 原辅料运输碳排（简化：距离×吨公里因子）│
├────────────────────────────────────────┤
│  外圈（Phase 3 远期）                   │
│  ├─ 涂料制造过程碳排（需要供应商数据）    │
│  ├─ 产品存储（制冷/温控能耗）             │
│  └─ 成品运输（物流追踪）                 │
└────────────────────────────────────────┘
```

**全生命周期碳排放核算公式：**

```
LCA_总碳排放（tCO₂e/月）= 
  工序端碳排（天然气 + 电力 + 涂料隐含）           ← 已有
  + 上游碳排（涂料制造 + 原辅料运输）               ← Phase 2 新增
  + 下游碳排（成品仓储 + 成品运输）                 ← Phase 3 新增

LCA_碳排强度（tCO₂e/万 m²）= LCA_总碳排放 / 当月喷涂面积
```

**对悖论判定的影响：**

引入 LCA 视角后，悖论判定可能出现 **"工序端悖论被全生命周期部分抵消"** 的新现象：

| 判定视角 | 示例结果 | 说明 |
|----------|----------|------|
| 工序端视角 | 水性漆切换 → VOCs -60%，天然气 +35%，C-P 从 0.75 → 0.48（减污增碳陷阱）| 传统判定 |
| 全生命周期视角 | 水性漆制造碳排 -15%（因子低），运输 -8%（本地采购），综合净变化 +12% | 上游抵消部分工序端增量 |

> **产品策略**：悖论模拟器提供 **"工序端视角 / 全生命周期视角"** 切换开关，两种视角并行展示，帮助企业做出更全面的技改决策。

- **与实时双算的区别**：模拟器是"事前预测"（技改前用），实时双算是"事中监测"（运行中用）

- 四大模块：污染评价（P）、能效评价（E）、碳排评价（C）、C-P 协同指数

- 支持 PDF 导出
- **数据来源**：月度填报数据 + 实时双算数据汇总

**预警中心 — AI 智能分级推送**

- 点击查看 AI 生成的 减污增碳/减碳增污悖论 诊断报告和改进建议

### 4.2 政府管理科功能

大屏从"数据展示"升级为 **"AI 主动态势感知 + 智能决策推荐"** 中枢，不再是人找数据，而是数据找人。

**L1 全域态势感知层（顶部）**
- **区域三维健康画像**：同时展示区域 C-P 协同指数、MCI 多污染物指数、EHI 环境健康指数三个核心指标，AI 自动标注最需关注的维度
- **AI 智能摘要**：LLM 自动生成 30 秒语音可读的区域态势摘要，如"今日辖区悖论预警 3 起，较昨日下降 40%。值得关注的是张镇工业园 MCI 指数下降 0.15，疑似过度燃烧导致 NOₓ 升高"
- **悖论弹幕流**：最新悖论事件像弹幕一样从屏底飘过，点击直达详情
- **预测性预警**：AI 基于时序模型预测未来 24h 悖论高发企业和时段，提前标黄

**L2 智能决策推荐层（中部）**
- **AI 调度建议生成器**：当悖论事件触发时，大屏自动弹出 LLM 生成的调度建议草案，工作人员可一键确认下发或修改后下发
- **错峰生产智能排班**：AI 自动计算辖区企业最优错峰运行方案，可视化展示各企业时段分配甘特图
- **资源调度模拟**："如果要求蓝天工业停产整改 3 天，对区域 C-P 指数的影响是？"——AI 实时模拟并给出量化预测

**L3 深度交互层（底部）**
- **语音/文字操控**："显示本周悖论趋势""对比蓝天工业和红星涂装"

- **一键生成汇报材料**：AI 自动将当前大屏数据组装为 PPT 提纲 + 图表，支持导出 Word/PDF

### 5.5 污碳协同三层指标体系 ⭐

**设计原则**：C-P 协同指数的核心价值在于 **"单一 trade-off 的锐度"**——回答一个具体问题："为了削减 VOCs，我多烧了多少碳？" 若将 PM2.5、SO₂、NOₓ、CH₄ 全部揉入同一公式，指标将失去叙事力和可行动性。因此平台采用 **分层指标体系**：C-P 保持聚焦（手术刀），新增 MCI 和 EHI 承载综合评价（体检报告）。

```
┌─────────────────────────────────────────────────────────────┐
│  第一层：C-P 协同指数（C-P Index）                           │
│  ├─ 聚焦：VOCs 削减 ↔ 碳排放增量                            │
│  ├─ 公式：max(0, 1 - ΔC / ΔP_threshold)                    │
│  └─ 用途：悖论识别、实时预警、调度决策、企业自检             │
├─────────────────────────────────────────────────────────────┤
│  第二层：多污染物协同指数（MCI, Multi-pollutant Coordination Index）│
│  ├─ 聚焦：VOCs + PM2.5 + SO₂ + NOₓ 联合减排效率             │
│  ├─ 逻辑：RTO 烧天然气不仅增 CO₂，也可能增 NOₓ（高温燃烧）   │
│  └─ 用途：识别"为了降 VOCs 却增了 NOₓ"的新悖论类型           │
├─────────────────────────────────────────────────────────────┤
│  第三层：环境健康综合评价（EHI, Environmental Health Index）  │
│  ├─ 聚焦：全口径污染物 + 碳排放 + 能耗的宏观画像             │
│  ├─ 权重：VOCs30% + NOₓ20% + PM2.515% + SO₂10% + CO₂20% + CH₄5%│
│  └─ 用途：企业排名、区域画像、汇报材料、公众披露             │
└─────────────────────────────────────────────────────────────┘
```

**第一层：C-P 协同指数（保留，不变）**

- **公式不变**：`max(0, 1 - ΔC / ΔP_threshold)`
- **ΔC 基础版**（默认）：仅计算碳排放增量
- **ΔC 严格版**（可选配置）：将 NOₓ 折算当量纳入

```
ΔC_base = (本期碳排强度 - 上期) / (本期 VOCs 去除强度 - 上期)
ΔC_full = ΔC_base + α · (本期 NOₓ 增量 / 本期 VOCs 去除增量)
```
其中 `α` 为 NOₓ 温室效应折算系数（默认 0，即不启用；严格模式下 α = 0.15）。

**第二层：多污染物协同指数（MCI）**

识别"末端治理副作用"——为降 VOCs 而过度燃烧，导致 NOₓ 超标。

```
MCI = Σ(w_i · P_i_norm) · (1 - β · NOₓ_penalty)

P_i_norm = 1 - (当前排放速率_i / 排放限值_i)    ← 各污染物归一化达标率
w_i = 污染物权重（VOCs 40% + NOₓ 25% + PM2.5 20% + SO₂ 15%）
NOₓ_penalty = max(0, NOₓ排放速率 / NOₓ限值 - 0.8)   ← NOₓ越限惩罚项
β = 惩罚系数（默认 0.5）
```

| MCI 区间 | 等级 | 说明 |
|----------|------|------|
| ≥ 0.8 | 优 | 多污染物协同控制良好 |
| 0.6–0.8 | 良 | 个别污染物有优化空间 |
| 0.4–0.6 | 差 | 存在末端治理副作用，需调整燃烧参数 |
| < 0.4 | 极差 | 典型"降 VOCs 增 NOₓ"悖论 |

**第三层：环境健康综合评价（EHI）**

企业级/区域级宏观环境画像，用于排名和汇报。

```
EHI（0–100）= 
  VOCs_score × 30%
  + NOₓ_score × 20%
  + PM2.5_score × 15%
  + SO₂_score × 10%
  + CO₂_score × 20%
  + CH₄_score × 5%

各污染物得分 = max(0, 100 - 100 × 排放速率 / 排放限值)
CO₂_score = max(0, 100 - 100 × 碳排强度 / 行业 P90)
```

**三层指标使用场景对照：**

| 场景 | 应该看哪层 | 原因 |
|------|-----------|------|
| 企业收到短信："C-P 指数跌破 0.4" | 第一层 C-P | 明确、可行动：检查 RTO 空烧 |
| 政府问："这家厂整体排放水平如何？" | 第三层 EHI | 全面、可比：行业排名 |
| 监测科发现：VOCs 降了但 NOₓ 飙升 | 第二层 MCI | 识别新型悖论：过度燃烧副作用 |
| 企业申请技改资金，需整体画像 | EHI + C-P | 既要看整体水平，也要看核心矛盾 |
| 区域月度汇报材料 | 第三层 EHI | 公众可读、领导易懂 |
| AI 悖论归因 | 第一层 C-P | 聚焦根因、精准调度 |

## 6. 业务规则与逻辑

### 6.1 悖论判定规则

**减污增碳陷阱：**
```
条件1：VOCs 排放浓度环比下降 ≥ 20%（或去除效率上升）
条件2：天然气消耗量环比上升 ≥ 30% 或碳排强度环比上升 ≥ 20%
条件3：产量变化 < 10%（排除产能扩张因素）

满足全部条件 → 判定为「减污增碳陷阱」
```

**减碳增污陷阱：**
```
条件1：天然气消耗量环比下降 ≥ 20% 或碳排强度环比下降 ≥ 20%
条件2：VOCs 排放浓度环比上升 ≥ 30% 或去除效率下降 ≥ 15%
条件3：产量变化 < 10%

满足全部条件 → 判定为「减碳增污陷阱」
```

**C-P 协同指数与 减污增碳/减碳增污悖论 联动：**
```
C-P 指数 < 0.4  →  自动触发 减污增碳/减碳增污悖论 标记
C-P 指数 0.4–0.6  →  触发协同失衡预警
C-P 指数持续下降（连续 3 天降幅 > 0.1） →  触发趋势预警
```

### 6.2 实时双算引擎规则

| 计算项 | 公式 | 更新频率 | 精度 |
|--------|------|----------|------|
| VOCs 排放速率 | 出口浓度 × 风量 × 10⁻⁶ | 5 分钟 | ±5% |
| VOCs 去除效率 | (入口 - 出口) / 入口 × 100% | 5 分钟 | ±3% |
| TVOC/NMHC/PM2.5/SO₂/NOₓ 排放速率 | 出口浓度 × 风量 × 10⁻⁶ | 5 分钟 | ±5% |
| CO 折算碳排放 | CO 流量 × 1.57 × 10⁻⁴ | 15 分钟 | — |
| CH₄ 折算碳排放 | CH₄ 流量 × GWP₂₈ × 10⁻⁶ | 15 分钟 | — |
| 天然气碳排放 | 天然气流量 × 1.63 × 10⁻⁴ | 15 分钟 | — |
| 电力碳排放 | 化石能源用电量 × 电网因子 × 10⁻³ | 15 分钟 | — |
| 绿电碳排放 | 绿电量 × 0 | 15 分钟 | — |
| C-P 协同指数 | max(0, 1 - ΔC / ΔP_threshold) | 每小时 | — |
| MCI 多污染物指数 | Σ(wᵢ·Pᵢ_norm)·(1 - β·NOₓ_penalty) | 每小时 | — |
| EHI 环境健康评分 | 加权污染物得分 + 碳排得分 | 每小时 | — |
| 空烧判定 | 入口 VOCs < 500 且 天然气 > 空烧量 × 1.2 | 每小时 | — |

### 6.3 污碳协同健康评分规则（企业工作台实时展示）

企业工作台首页展示的「污碳协同健康评分」是实时更新的简化综合评分（0–100），基于最新实时双算数据计算，无需等待月度报告。

**计算公式：**
```
健康评分 = 污染分×30 + 能效分×25 + 碳排分×25 + 协同分×20
```

**各分项计分（均为 0–100 分）：**

| 分项 | 计分规则 |
|------|----------|
| **污染分（30%）** | 近7日 VOCs 均值 < 限值得 100 分；每超 1 天扣 15 分；超标 ≥ 3 天得 0 分 |
| **能效分（25%）** | RTO 热回收效率 ≥ 95% 得 100 分；< 90% 得 60 分；< 85% 得 30 分 |
| **碳排分（25%）** | 碳排强度 ≤ 区域 P25 得 100 分；P25–P50 得 75 分；P50–P75 得 50 分；> P75 得 25 分 |
| **协同分（20%）** | C-P 指数 ≥ 0.8 得 100 分；0.6–0.8 得 80 分；0.4–0.6 得 50 分；< 0.4 得 20 分 |

**评分等级：**
- 🟢 优秀（≥85）：各项表现均衡，建议维持
- 🟡 良好（70–84）：个别维度有优化空间
- 🟠 一般（60–69）：存在明显短板，需关注
- 🔴 较差（<60）：存在严重问题，建议立即排查

**更新频率**：每小时自动更新（基于最新实时双算结果）

**与三评合一报告的关系**：
- 健康评分是「实时快照」（基于近 7 天数据），用于企业日常自检
- 三评合一报告是「月度体检」（基于完整月度数据），用于深度分析和存档
- 两者评分维度相同但时间窗口不同，健康评分可能波动更大

**三层指标在健康评分中的映射**：
- C-P 协同指数（第一层）直接参与协同分计算
- MCI 指数（第二层）影响污染分中的 NOₓ 子项权重
- EHI 评分（第三层）作为辅助参考展示在企业档案卡片的"宏观画像"区域

### 6.4 三评合一报告评分规则

| 评分维度 | 满分 | 计分规则 |
|----------|------|----------|
| 污染评价（P） | 100 | VOCs 达标率×40 + 去除效率×30 + 涂料结构优化×30 |
| 能效评价（E） | 100 | 热回收效率×40 + 空烧控制×30 + 能源结构×30 |
| 碳排评价（C） | 100 | 碳排强度对标×40 + 配额余量×30 + 减碳潜力×30 |
| C-P 协同指数 | 1.0 | 按 6.1 规则计算 |

**AI 摘要四级判定：**
- 优秀（P≥85, E≥85, C≥85, C-P≥0.8）："整体表现优秀，建议维持并推广经验"
- 良好（P≥70, E≥70, C≥70, C-P≥0.6）："整体良好，关注 {最低分维度}"
- 一般（P≥60 或 E≥60 或 C≥60）："存在明显短板，{最高优先级建议}"
- 较差（P<60 或 C<60 或 C-P<0.4）："存在严重问题，建议立即启动整改"

    ↓

| 场景 | 处理方式 |
|------|----------|

### A. 碳排放计算公式

```
天然气碳排放（tCO₂）= 天然气消耗量（万 Nm³） × 1.63

电力碳排放（tCO₂）= 化石能源用电量（万 kWh） × 电网因子
  ── 电网因子：华北电网 0.5703，北京电网 0.3512
  ── 绿电碳排放 = 0（不计入碳排放核算）
  ── 化石能源用电量 = 总用电量 - 绿电量

涂料隐含碳排放（tCO₂）= 涂料用量（kg） × 涂料碳排放因子（kg CO₂/kg） / 1000

企业碳排放强度（tCO₂/万 m²）= 总碳排放 ÷ 喷涂面积（万 m²）
区域碳排强度 = Σ(各企业碳排放量) ÷ Σ(各企业喷涂面积)
```
